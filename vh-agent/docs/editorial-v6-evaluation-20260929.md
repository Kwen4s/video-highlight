# 编辑取舍 v6：实现与验证（2026-09-29）

> 本文是 v6 历史失败记录。当前实现已替换复核字段、候选账本和工具状态机；现行设计以 `react-video-agent-design.md` 为准。

本轮修改观察登记、独立复核和最终选择的职责，沿用单主 Agent 与实际成片独立复核。没有新增模型、依赖或 Agent 层次。

## 实现

- 新增 select_highlights 独立工具，删除旧 select 动作、ranked_event_ids、按分数自动填满预算和结束时重新计算选择的路径。
- 每个 ready 计划恰好对应一次保留/舍弃决定，保留项顺序是优先级；舍弃理由及 duplicate_of 持久保存。全舍弃合法，不合预算则不提交，让 Agent 修订。重复价值处置不合并事件、不改边界。
- 完整选择与业务状态一起提交。恢复、导出使用同一份选择；partial 的公开 highlights 为空，ready 计划保留在 state。
- 独立复核保留实际所见、理解和关键表达检查、具体缺陷；删除 worth_clipping 布尔硬门槛，价值分数与解释供最终取舍参考。
- 观察登记明确区分没有发现候选与发现后排除；不增加关键词判定或特定剧情规则。compare 返回完整待选池和已排除事件简要索引。
- 评分保留原始边界 IoU，增加事件替代边界、可选命中和时间重复诊断。可选命中从推荐精度分母排除，不提高推荐召回；已排除但登记过的事件也计入新口径候选池。

## 本地验证

Agent 全量测试 161 项及后端 23 项通过。覆盖选择提交后、导出前中断恢复，以及空白理由/无效重复关系。Ruff 检查通过。

## 实测与对照

固定五视频运行目录：`outputs/evaluations/editorial_v6_20260929/`。使用 reviewed-five-v2 和原来的 3–30 秒、数量与总时长不限、允许重叠配置。检测输入不含答案。本地候选模型未启用。

v4/v5 旧输出已用新评分器离线重算，未调用模型；重算前报告保存为 metrics.before_event_scoring.json 与 report.before_event_scoring.md。IoU≥0.5 的事件口径：v4 P=1、R=0.75、F1≈0.857；v5 P=0.75、R=0.75、F1=0.75。新口径承认重生事件的替代剪法，不能与旧原始边界分数混比。

当前五视频是暴露过预测的 AI 开发复标，仍待人工审定；时间匹配不检查人物身份、事实与疑问是否混淆，也不代表人工采用率。重复计数为时间匹配诊断，不能证明语义上没有重复。

第四条实际复核把缺少后续反转写入 complete=False 和 issues，说明去掉 worth_clipping 仍不能保证语义上的职责分离。整轮运行结束后，明确补充了复核提示中的字段分工，并对同一真实片段做一次独立复查，结果单独保存于 review_scope_recheck/，不改写主运行结果。收尾还删除了进度中重复且含旧 select 名称的动作提示，修正银标运行元数据，恢复了无关格式改动，并补充离线核心证据覆盖诊断。整轮源码保持原冻结快照；最终提示没有重新跑全套五视频。

第一条医院视频已完成，输出 11.3–33.833313 秒。主 Agent 把身份疑问描述为确认，复核 visible_event 写了“可能”，但复核 reason 和最终选择理由仍写成确认。协议运行成功不等于事实表达准确；该问题保留用于后续审查。

第二条十亿视频 20 次模型调用后因 stagnant_steps=8 以 partial 停止，没有事件或最终高光。它反复调用 scan_video，另有重复字幕分页。此轮无法检验其栽赃取舍效果，未清零停滞计数或改成成功。

## 最终复核提示的单片复查

同一砚知山河意片段，补充字段分工后的独立复查成功，耗时 13.9 秒。返回 standalone=true、complete=true、issues=[]、score=0.6，理由为人物背景、人际氛围与情感看点。它没有增加主运行输出，也没有覆盖先前的失败复核；一次非确定模型调用不足以证明提示改动稳定有效。五视频统计不包含此次额外调用。
