时间 IoU 不直接核验剧情身份，也不评价片段是否值得采用。标注审查后：第一条有边界粒度差异；第二条存在漏标，同时 Agent 对已识别的另一事件未作登记；第三、第四条主要是价值标准分歧，不能直接认定为漏看。

此前依据旧标签作出的可用性判断证据不足，需以标注审查后的事件事实与人工价值评价为准。当前实现的流程约束已通过测试。下一轮应先明确并验证冲突类事件的采用标准、检查全片观察后的漏检、减少重复检索；统一模型配置与本轮协议后再比较，不针对五条剧情写专用规则。人工标注的事件标准和成片上下文范围也应由标注人员复核。
