## 看方法之前需要固定的标注口径

让人工对候选分别判断：事件描述是否属实、是否值得单独选用、必要证据在哪里、怎样的上下文范围可以接受。标明“必选 / 可选 / 非高光 / 有争议”，不要把“有事件”直接当“必须输出”。核对整片是否漏标合理候选；无法保证穷尽时，未匹配预测应进入人工复核，而不是直接视为误检。

一个事件可以允许多个完整剪辑边界，但这些区间应由人工独立给出，不能从待评预测反推。事件发现与成片质量分开报告：IoU 保留作时间定位指标，同时核对事件身份、必要证据和独立完整性，不能简单降低 IoU 阈值掩盖问题。

在此基础上，方法的首要可验证问题是：观察结论中的重要候选未必进入事件池；现有完成条件只检查已登记事件，无法保证已观察但未登记的候选被处置。重复字幕读取和接口超时也是已记录的工程问题。先围绕这些证据修正方法，不为迎合旧 AI 标签增加“凡有冲突必输出”的规则。
