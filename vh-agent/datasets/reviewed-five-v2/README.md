## 数据字段

- `annotations.json`：每条记录包含 `highlights`（推荐）、`optional_highlights`（可选）、`context_events`（背景）和 `excluded_intervals`（未另立事件的区间）。
- 每个候选有稳定 `event_id`、事件事实、选用理由、建议成片边界及分角色证据区间。
- `alternative_clips` 属于同一事件的其他完整表达，不是额外目标数。
- `annotation_status=labeled` 只表示标注已写完；`annotation_tier=ai_reviewed`、`human_verified=false` 明确来源，不能把 labeled 解读为人类金标。
- `manifest.jsonl` 保留视频位置和原有 split；没有把 train 改名为独立测试。
- `protocol.json` 保存标注标准、旧标签指纹和已看过预测这一事实。

## 使用范围

适合交给标注人员审阅、定位事件、核对边界与讨论采用标准。帧证据位于 `../../outputs/annotation_audit_20260929/{video_id}/`，其中 `relabel_boundaries.jpg` 为此次补抽的边界画面。

现有评测器只读取 `highlights`，**尚不处理可选候选及同事件的替代边界**。直接评分会把选中可选事件的预测当作未匹配，因此这版先作为复标数据，不直接据此宣称准确率。后续接入时应先匹配推荐事件，再将匹配可选候选的输出单列；它们不增加必选召回分母，也不直接算误检。替代剪辑按同一 event_id 只计一次。人类定稿后冻结新版本，再开展独立效果比较。
