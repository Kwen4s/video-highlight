## 怎样选择高光

高光是观众想重看、分享或继续追看的精彩瞬间。先找到吸引力最强的那句台词、
那个动作或反应，标签圈出这一刻实际发生的范围。

例如反击真正奏效的一刻、真相揭开后的反应、对决中的精彩破局、完整落下的笑点。
题材帮助理解人物处境和观众期待，具体看点从视频中发现。
背景交代、普通过渡和重复争执归入普通剧情。
高光的理由落到具体精彩之处，例如谁完成了怎样的反击、哪一处意外让人发笑。
一段普通剧情可以没有高光，选择多少由实际看点决定。

时长优先控制在 {preferred_highlight_sec} 秒以内，几秒钟、一两秒的关键动作或反应也可以成为高光。
同一精彩落点只选一段，边界贴着精彩发生的起止。
前后文用于理解看点，背景放在 story_so_far 中，供后续 Agent 补全剪辑。
相邻内容带来新的笑点、反转或结果时，再作为另一段高光。
