# VH Frontend

Electron 桌面前端，只通过 `VITE_API_BASE_URL` 指向的 FastAPI 公开接口上传视频、查询任务、播放原片和进行人工复核。前端不会读取后端文件路径或 `vh-agent` 内部字段。

工作区支持一次选择多个视频并显示逐文件上传、服务端排队和分析进度。未完成的分析可以从检查点继续。任务归档可以按文件名、任务编号和高光内容检索，并按状态筛选或排序。

选择高光后，可以直接拖动完整原片时间轴上的入点和出点，也可以输入精确秒数。保存时使用后端乐观版本号校验；片段仍受 0.5–24 秒范围限制。

人工复核中标记为“已采用”的片段可以追加广告并导出新视频：

- 使用 3 个内置短剧片尾预设，修改主文案、辅助文案、展示时长和二维码；
- 导入本机已有的广告视频并沉淀到个人素材库；
- 将单个高光与片尾广告合成为 H.264/AAC MP4，通过系统保存对话框选择输出位置。
- 不添加广告，直接把当前高光导出为 H.264/AAC MP4。

入口位于左侧“工作区 → 03 广告编排”；该页面集中列出所有已采用高光及其广告配置状态。高光卡片中的“加广告”仍保留为快捷入口。

媒体合成只发生在 Electron 主进程。渲染层只传递公开任务字段、广告素材 ID 和用户选择，不接触服务端物理路径；导出不会修改原片。

后端在任务响应中返回相对 `source_url`，前端再以 `VITE_API_BASE_URL` 为基准解析；因此开发、测试和生产环境可以独立部署，不需要把服务器地址写入任务数据。

```powershell
nvm use 24.14.1
npm install
npm run dev
```

复制 `.env.example` 为相应环境配置，并设置不带末尾斜杠的后端地址：

```dotenv
VITE_API_BASE_URL=http://127.0.0.1:8777
```
