# VH Frontend

Electron 桌面前端，只通过 `VITE_API_BASE_URL` 指向的 FastAPI 公开接口上传视频、查询任务、播放原片和进行人工复核。前端不会读取后端文件路径或 `vh-agent` 内部字段。

高光提取入口保留大视频导入框，支持一次选择多个视频。选择有效文件后立即进入流程页，依次展示上传、服务端排队与分析状态；完整交付后进入人工复核。批量选择时保持展示本批第一条任务，其余任务可从归档打开。任务归档从文件选择时就显示本次导入，包括等待上传、上传中、等待服务端确认、排队与分析状态；收到服务端回执后按同一任务编号替换导入记录。高光提取页不显示批量任务队列，侧栏切换页面会保留当前任务且上传继续进行。通过页面右上角的导入按钮开始新任务。归档可以按文件名、任务编号和高光内容检索，并按状态筛选或排序。

上传中展示实际传输量、百分比与平均速度；请求体传输结束后显示“等待服务端确认”，不提前显示任务已接收。上传失败或取消的记录保留在当前会话归档中，可以重新上传或移除；错误后会查询同一公开任务接口，确认服务端是否已接收，避免丢失已创建的任务。未收到接入回执的记录不跨应用重启保存。后端健康状态不代表原片已经传输完成。

导入页的“新任务要求”支持提取目标、最短与最长片段时长、数量上限、总时长上限、上下文重叠和视频语言。数量或总时长留空表示不限，每个排队文件保存导入时的配置。可预先添加 SRT、VTT、ASS、SSA 或 SUB 字幕：批量视频按不区分大小写的同名文件匹配；单个视频可搭配一份任意名称字幕。匹配失败时不会提交任务，成功入队后清空待添加字幕。

进度页沿用原有流程节点、详情与回执布局，展示后端公开的全片覆盖率和待整理观察、待确认线索、待核验事件、待复核片段数量。覆盖率达到 100% 不代表结果已交付；只有 `status=completed` 且 `completion=complete` 才进入三栏人工复核。`partial` 与失败任务保留进度和“继续分析”入口，调用 `POST /api/jobs/{job_id}/resume`；是否存在可恢复检查点由服务端判断，已有人工编辑的结果不能继续分析。

五个主节点保留原有圆形节点与连线，在节点间标注交接内容，并提供共 32 项可查看详情。每项展示用途、输入、输出和实际回传值；视频分析分为全片检查、辅助感知、事件核验、成片复核四组。辅助感知包含 ASR / 字幕检索、OCR、原帧检查、语义检索和本地候选定位，标明能力可调用、未启用或状态未回传。按需能力不会被伪装成固定并行流程或逐项完成进度。

任务响应新增 `task`（本任务原始提取要求、是否提供字幕）和 `workflow`（经过筛选的处理快照）。右侧展示检查区间、下一原片范围、事件与候选量、文字读取量、就绪成片和分析轮数。前端兼容旧接口已经提供的公开计数与能力标记，未知数据不显示为 0；历史任务缺少的原始要求不会用当前新任务设置代替。本次会话提交的新任务保留自己的参数快照。详情不读取 Agent trace、内部事件 ID 或服务端路径。

选择高光后，优先播放后端公开 `clip_url` 指向的已复核成片；没有成片地址时按当前边界预览原片。可以拖动完整原片时间轴上的入点和出点，也可以输入精确秒数。保存时使用后端乐观版本号校验；片段至少 0.5 秒且位于原片范围内，不再设置旧版 24 秒编辑上限。修改边界后后端会清空旧 `clip_url`，播放器和导出随之使用原片的新范围。事件详情随播放器区域宽度调整分栏，保留候选、播放器与编辑助手的三栏框架。

人工复核中标记为“已采用”的片段可以追加广告并导出新视频：

- 使用 3 个内置短剧片尾预设，修改主文案、辅助文案、展示时长和二维码；
- 导入本机已有的广告视频并沉淀到个人素材库；
- 将单个高光与片尾广告合成为 H.264/AAC MP4，通过系统保存对话框选择输出位置。
- 不添加广告，直接把当前高光导出为 H.264/AAC MP4。

入口位于左侧“工作区 → 03 广告编排”；该页面集中列出所有已采用高光及其广告配置状态。高光卡片中的“加广告”仍保留为快捷入口。

媒体合成只发生在 Electron 主进程。渲染层只传递公开任务字段、广告素材 ID 和用户选择，不接触服务端物理路径；导出不会修改原片。

后端在任务响应中返回相对 `source_url`，前端再以 `VITE_API_BASE_URL` 为基准解析；因此开发、测试和生产环境可以独立部署，不需要把服务器地址写入任务数据。

```powershell
nvm use 24.14.1
npm install
npm run dev
```

复制 `.env.example` 为相应环境配置，并设置不带末尾斜杠的后端地址：

```dotenv
VITE_API_BASE_URL=http://127.0.0.1:8777
```

验证命令：

```powershell
npm test
npm run test:ui
```

`test:ui` 先构建页面，再通过隐藏 Electron 窗口与本地模拟接口检查配置校验、字幕上传、未完成结果、恢复冲突与重复提交、上传期间切页与归档、流程详情与 ASR/OCR 能力状态、成片播放、边界编辑、流式回复及 1080 × 700 最小窗口布局。不会连接实际推理服务；截图输出到仓库的 `.cache/frontend-ui/`。
